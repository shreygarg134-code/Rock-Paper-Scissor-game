# Rock Paper Scissors 🎮

A modern, neon-themed take on the classic Rock Paper Scissors game. This project was built to practice core web development concepts, transitioning from basic alert-based logic to full DOM manipulation and state management.

## ✨ Features
* **Play vs. Computer:** Algorithm uses `Math.random()` to generate perfectly balanced 33.3% probability moves.
* **Persistent Scoring:** Utilizes browser `localStorage` to save Wins, Losses, and Ties across page refreshes.
* **Dynamic DOM Updates:** Displays live game results, current scores, and visual move indicators using `innerHTML` and `querySelector` without page reloads.
* **Interactive UI:** Custom glowing 3D graphics with CSS-driven hover scaling and active click states for a responsive feel.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom gradients, transparent buttons, and interaction animations.
* **JavaScript (Vanilla):** Game logic, local storage integration, and DOM rendering.

## 🚀 How to Run
1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Alternatively, you can play the live version here: https://shreygarg134-code.github.io/Rock-Paper-Scissor-game/
